PASOS PARA EJECUTAR EL PROGRAMA:

1.En MySQL Workbench, como root, correr database/1_sistemaReservas.sql, luego el 2 y luego el 3, con el rayo ⚡.
2.Correr servidor/ServidorApp (clic derecho → Run). Debe decir “Servidor escuchando en el puerto 12345”. No detenerlo.
3.Correr el Frontend con javafx:run en Maven y entrar con admin/1234, ISS/ISS o cualquier otro usuario.

Para ver las alertas abran una segunda ventana: clic derecho en Lanzador.java → Run, y entren con otro usuario.
Las alertas se verán reflejadas en las reservas creadas por otro usuario.
